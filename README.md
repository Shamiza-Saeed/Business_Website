# Shamiza Solutions - Business Website 🚀

Welcome to the official repository of **Shamiza**, a modern and responsive multi-page agency website designed to showcase digital services, portfolio case studies, and business information with a slick, high-performance UI.

---

## ✨ Features

* **Modern & Clean Design:** Custom styled with a corporate blue accent theme (`#2563eb`) and dark slate typography.
* **Fully Responsive:** Mobile-first layout that looks great on smartphones, tablets, and desktop displays.
* **Interactive Modals:** Dynamic case study pop-ups for portfolio items.
* **Dark Mode Toggle:** Smooth theme switcher for better night-time browsing.
* **Interactive Elements:** FAQ accordion, animated stats counters, and validated contact forms.
* **Zero Dependencies:** Built purely using core web technologies without heavy frameworks.

---

## 🛠️ Tech Stack

* **HTML5** - Clean semantic structure
* **CSS3** - Modern layouts using Flexbox, CSS Grid, and custom variables
* **Vanilla JavaScript (ES6+)** - Dynamic DOM manipulation and interactivity
* **FontAwesome** - Vector icons
* **Unsplash** - High-quality dynamic project imagery
